# ideasoft-selenium-playwright-java-automation
Selenium &amp; Playwright based Java automation test project


## ⚙️ Kullanılan Teknolojiler

- **Java 17+**
- **Playwright for Java**
- **Maven** (proje yönetimi ve bağımlılıklar)
- JUnit 

🧩 Özellikler

Page Object Model (POM) tasarım deseni

Selenium + Playwright entegrasyonu

Farklı test senaryoları için genişletilebilir yapı

Maven ile kolay bağımlılık yönetimi
